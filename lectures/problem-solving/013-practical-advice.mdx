## tax report automation / better solution

LLM не приймає фінальні факти. Вона лише витягує дані з документів і пояснює невпевнені місця. Якість дають frozen state, source links, детерміновані lookup-таблиці, формули, API НБУ та fail-fast валідація.

```mermaid

  pdf["PDF / scan"]
  text["Text layer<br/>pdftotext / pdfplumber"]
  vision["Vision model<br/>JSON Schema"]
  confidence["Field confidence<br/>null if unclear"]
  crosscheck["Code cross-check<br/>between sources"]
  double["Double pass<br/>critical numbers"]
  review["Human review<br/>only mismatches"]

  text -->|"є текст"| state

  vision --> confidence --> crosscheck --> double --> state

  double -. "diff" .-> review
  review --> state

  class text,crosscheck,double,state decisionChosen
  class vision,confidence decisionMuted
  class review decisionFinal
```

### не просимо модель “прочитати документ”

Один документ до віжн vision-моделі, через саб агента, structured output, confidence на кожне поле. 
Далі точність дає не модель, а cross-check кодом і review тільки там,
де не зійшлося.
