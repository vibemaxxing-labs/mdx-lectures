## Auth складається з двох питань

| Тип | Питання | Приклади |
| --- | --- | --- |
| Authentication | Хто користувач? | Email magic link, OAuth, passkeys |
| Authorization | Що дозволено? | Roles, permissions, ownership |
| Session | Як пам'ятаємо вхід? | Cookies, JWT, provider session |

<Callout variant="principle" title="Design">
  Спочатку опиши ролі та доступи мовою продукту. Технологія входу йде після цього.
</Callout>
