## > database / типи

1. Relational — структуровані дані зі зв'язками
2. Document - гнучка схема, JSON-контент
3. Key-Value — кеш, сесії, швидкий lookup
4. Wide-Column — аналітика, великі обсяги
5. Graph — зв'язки між сутностями
6. Time-Series — метрики, моніторинг, IoT
7. Search Engine — повнотекстовий пошук, релевантність
8. Vector — семантичний пошук, ембедінги
