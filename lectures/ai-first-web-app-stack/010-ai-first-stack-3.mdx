## > backend / нахіба?

1. потрібна безпека / auth
2. потрібен shared state (кілька юзерів/пристроїв мають бачити одні й ті ж дані в реальному часі)
3. потрібні third party integrations (API ключі, вебхуки, OAuth flows, платіжні системи)
4. потрібні важкі обчислення (batch processing, ML inference, генерація звітів, CRON-задачі. Те що має працювати без відкритої вкладки в браузері)
