## Секрети не живуть у коді

```env
DATABASE_URL="..."
NEXT_PUBLIC_APP_URL="https://example.com"
STRIPE_SECRET_KEY="..."
```

| Prefix | Де видно |
| --- | --- |
| `NEXT_PUBLIC_*` | Browser bundle |
| Без public prefix | Server runtime |

<Callout variant="warning" title="Boundary">
  Все, що потрапило у frontend bundle, треба вважати публічним.
</Callout>
