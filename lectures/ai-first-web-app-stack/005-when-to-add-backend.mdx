## Починай з найпростішої архітектури

| Потреба | Достатньо FE | Потрібен BE / DB |
| --- | --- | --- |
| Landing page | Так | Ні |
| Калькулятор без акаунтів | Так | Ні |
| Особистий кабінет | Ні | Так |
| Платежі або ролі | Ні | Так |

<Callout variant="warning" title="Rule">
  Якщо стан не треба зберігати, захищати або ділити між користувачами - backend може бути зайвим.
</Callout>
