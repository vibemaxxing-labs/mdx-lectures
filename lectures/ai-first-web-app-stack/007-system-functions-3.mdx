### > paywall

```mermaid
sequenceDiagram
    actor User
    participant App
    participant Backend
    participant Billing

    User->>App: Open premium content / feature
    App->>Backend: Check access status
    Backend-->>App: Access denied

    App-->>User: Show paywall
    User->>App: Select plan and continue
    App->>Billing: Start payment
    Billing-->>App: Payment success

    App->>Backend: Update subscription / entitlement
    Backend-->>App: Access granted
    App-->>User: Unlock content / feature
```
