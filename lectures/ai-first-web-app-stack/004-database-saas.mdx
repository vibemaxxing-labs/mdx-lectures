## База як сервіс знімає операційну роботу

| Сервіс | Модель | Коли пасує |
| --- | --- | --- |
| MongoDB Atlas | Document DB | Гнучкі JSON-подібні об'єкти |
| Supabase | Postgres + Auth + Storage | Реляційні дані, SQL, швидкий backend-lite |

<Callout variant="tip" title="Практика">
  SaaS база потрібна не через моду, а коли треба надійно зберігати стан між сесіями, користувачами або пристроями.
</Callout>
