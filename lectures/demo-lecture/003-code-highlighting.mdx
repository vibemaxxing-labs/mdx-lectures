## Code blocks are primary slide objects

```tsx
type SlideFrontmatter = {
  title: string;
  subtitle?: string;
};

export function SlideTitle({ title }: { title: string }) {
  return <h1>{title}</h1>;
}
```

The language label, muted panel, and wrapped lines keep examples readable without adding scroll.
